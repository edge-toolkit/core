GPU Probe

This page runs small probes on your device's GPU through WebGL and WebGPU -- shader arithmetic, clears, blending and canvas drawing -- and reads back the exact results, which differ slightly between GPUs, drivers and browsers. It says whether the registry already knows your device. The results are sent only when you choose to, though a probe server serving this page is told how the run went, its canvas results among it.

        GitHub takes one file from a link, and a link only so long, so the GPUs are split across files: each link opens a pull request of its own.

        How sending works

        Each link opens GitHub's page for adding a file to the registry, with these results filled in, which needs a GitHub account. GitHub makes a copy of the repository for you, and opens a pull request with the file when you press "Propose changes".

        Without a GitHub account, download each file instead and email it to john.vandenberg@curtin.edu.au.

        To submit more data than a browser can measure, read the et-gpu-probe README.
